# CarbonWise

Carbon footprint platform: data input, analyses, objectives and PDF reports.

## Features

- Emission data input
- Analyses and objectives
- PDF report export with jsPDF

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- jsPDF

## Getting Started

```bash
git clone https://github.com/ghostland-dev/carbonwise-platform-v2.git
cd carbonwise-platform-v2
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
